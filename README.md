# TEMANAKSES

Accessibility-first adaptive learning platform for Indonesian students. The project explores how reading controls, keyboard navigation, local-first storage, and contextual assistance can make digital learning more usable.

## Highlights

- Reading presets for different focus and visual needs
- Bionic reading and focus ruler
- High-contrast, dark, soft, and standard themes
- Keyboard navigation and Indonesian text-to-speech
- Interactive glossary and contextual learning assistant
- Quizzes, spaced repetition, notes, bookmarks, and progress backup

## Tech stack

TypeScript · React · Vite · Zustand · React Router · Web Speech API · Node.js

## Run locally

```bash
npm install
npm run dev
```

Keep private API keys in `.env.local`, never in Git.

## Why it matters

TEMANAKSES is a practical exploration of inclusive UX for education: accessibility is treated as a core product feature, not a final polish step.
